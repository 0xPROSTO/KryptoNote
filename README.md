# ZeroXX-KryptoNote

ZeroXX-KryptoNote - локальное приложение для работы с заметками, медиа и связями между ними на бесконечном зашифрованном холсте.

Проект сделан для тех случаев, когда обычного списка заметок уже мало: нужно разложить идеи, файлы, фрагменты текста, изображения и видео в свободной форме, связать их между собой и сохранить всё в приватной базе без облаков и внешних аккаунтов.

## Что это

ZeroXX-KryptoNote объединяет визуальную доску, базу знаний и защищённое хранилище. Вместо папок и линейных документов используется граф: каждый объект лежит на холсте как отдельный узел, а связи между узлами помогают собирать структуру вокруг темы, проекта или исследования.

Приложение подходит для:

- личных баз знаний;
- рабочих и учебных материалов;
- заметок по проектам;
- визуального планирования;
- расследований, исследований и схем;
- хранения приватных медиа рядом с текстовым контекстом.

## Основные возможности

- Бесконечный холст с плавной навигацией.
- Текстовые, графические и видео-узлы.
- Визуальные связи между объектами.
- Поиск по заметкам.
- Импорт и просмотр медиа внутри приложения.
- Экспорт текстовых материалов в Markdown.
- Резервные копии проектов.
- Смена пароля без пересоздания базы вручную.
- Отдельные `.zrx` проекты, которые удобно переносить и архивировать.

## Приватность

ZeroXX-KryptoNote работает локально. Проекты хранятся на устройстве пользователя, не требуют регистрации и не зависят от внешнего сервера.

Данные проекта шифруются, а пароль используется для доступа к ключу базы. Крупные файлы хранятся чанками, поэтому приложение может работать с тяжёлым контентом без необходимости держать весь файл в памяти целиком.

Для видео используется diskless streaming: расшифрованные данные передаются в плеер через память и не сохраняются во временные файлы на диск.

## Безопасность

- AES-256-GCM для шифрования данных.
- Argon2id для получения ключа из пароля.
- Отдельный ключ данных для проекта.
- Проверка целостности зашифрованных данных.
- Автоматическая миграция старого формата базы при открытии проекта.
- Backup перед рискованными операциями вроде миграции или смены пароля.

Пароль нельзя восстановить. Если пароль потерян, доступ к проекту будет потерян вместе с ним.

## Формат проекта

Каждый проект хранится в отдельном `.zrx` файле. Внутри используется SQLite с зашифрованными полями и чанками для медиа.

Такой формат даёт несколько практичных преимуществ:

- проект можно переносить как обычный файл;
- можно хранить несколько независимых баз;
- удобно делать резервные копии;
- данные остаются локальными;
- проект не привязан к конкретной папке или аккаунту.
